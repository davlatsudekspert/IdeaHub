# Eski versiya (arxiv)

Bu papka — MindHub'ning avvalgi "O'zbek Reddit" uslubidagi versiyasi (Node.js +
Express-style xom HTTP server + PostgreSQL + Railway). Loyiha taqdimotdagi
yangi g'oya (AI asosidagi fuqarolik tashabbuslari platformasi) asosida
Cloudflare Workers'ga to'liq qayta qurildi — yangi kod repo ildizidagi
`wrangler.toml`, `src/`, `migrations/`, `public/` ichida.

Bu papka faqat tarixiy ma'lumot sifatida saqlanadi (eski Postgres'da qimmatli
ma'lumot yo'q edi, shuning uchun migratsiya qilinmadi). Ishga tushirish uchun
yo'riqnoma `legacy-node-app/src` ichidagi eski kodga tegishli emas.
